# Releases TriPrep

Ce dossier contient les APK de l'application TriPrep.

## Téléchargement

L'APK le plus récent est disponible ici : `TriPrepApp-latest.apk`

## Installation

1. Téléchargez le fichier APK
2. Sur votre appareil Android, activez l'installation depuis des sources inconnues dans les paramètres
3. Ouvrez le fichier APK pour installer l'application

## Fonctionnalités

- Calculateur Course à Pied (VMA/VO2max via test Semi-Cooper)
- Calculateur Natation (zones V2/V3/V4 via test 400m)
- Calculateur Vélo (zones FTP)
- Planificateur d'entraînements avec calendrier
- Notifications programmables pour les entraînements

## Mise à jour automatique

Ce dossier est mis à jour automatiquement par GitHub Actions à chaque build réussi.
